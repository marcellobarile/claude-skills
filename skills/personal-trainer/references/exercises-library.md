## Equipment Tiers {#equipment-tiers}

**Tier 0 — Bodyweight only**
**Tier 1 — Bands / light dumbbells (5–30 kg range)**
**Tier 2 — Adjustable DBs + bench**
**Tier 3 — Full DB rack + cables**
**Tier 4 — Barbell + squat rack / power rack**
**Tier 5 — Olympic platform / specialized equipment**

Each exercise is tagged with the minimum tier required.

## Lower Body — Squat Pattern {#squat}

| Exercise | Tier | Primary muscles | Notes |
|----------|------|----------------|-------|
| Air squat / bodyweight squat | 0 | Quads, glutes | Foundation; good for mobility work |
| Goblet squat | 1 | Quads, glutes, core | DB or KB; great for beginner loading |
| Bulgarian split squat (BW) | 0 | Quads, glutes, hip flexors | High intensity without load |
| Bulgarian split squat (DB) | 1 | Quads, glutes | Primary unilateral squat for home trainers |
| Box squat (BW/DB) | 1 | Quads, glutes, hamstrings | Reduces knee shear; good for knee rehab |
| Leg press | 3 | Quads, glutes | Machine; adjustable ROM, knee-friendly option |
| Hack squat machine | 3 | Quads | High quad isolation, fixed ROM |
| Front squat | 4 | Quads, core | More upright torso; requires mobility |
| Back squat (high bar) | 4 | Quads, glutes | Hypertrophy-biased squat variant |
| Back squat (low bar) | 4 | Glutes, hamstrings, quads | Strength-biased; powerlifting standard |
| Zercher squat | 4 | Quads, glutes, core | Unusual loading; good trunk demand |
| Safety bar squat | 5 | Quads, glutes | Reduces shoulder and wrist stress |

**Injury substitutions:**
- Knee pain (anterior): box squat, goblet squat with reduced depth, leg press
- Hip impingement: high-handle trap bar squat, goblet squat with stance adjustment

## Quick substitution guide by equipment tier

If user only has **Tier 0 (bodyweight)**:
- Squat → air squat, pistol progression, BW Bulgarian
- Hinge → glute bridge, single-leg glute bridge, Nordic curl
- Push → push-up variations, pike push-up
- Pull → inverted row, pull-up (if has bar)
- Core → plank, dead bug, hollow body

If user only has **Tier 1 (bands + light DBs)**:
- Same as above + goblet squat, DB RDL, DB press, DB row, band pull-apart

If user only has **Tier 2 (adjustable DBs + bench)**:
- Full hypertrophy program possible. All DB press/row/squat variations.

If user has **Tier 3 (+ cables)**:
- Adds cable fly, cable row, lat pull-down, pallof press, face pull.

If user has **Tier 4 (+ barbell/rack)**:
- Full strength programming: squat, deadlift, bench press, OHP.
